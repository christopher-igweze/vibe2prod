Architecture Context

A multi-tool AI CLI application written in Go with a SvelteKit web frontend. The core functionality uses pattern-based AI prompting (200+ patterns in data/patterns/) to analyze, extract, summarize, and transform text content. Supports multiple AI providers (OpenAI, Anthropic, Ollama, AWS Bedrock, Perplexity, Google Gemini). Includes auxiliary tools for changelog generation, code context extraction, and PDF conversion. The web interface provides a chat UI and pattern browsing. All AI calls are authenticated via environment API keys; the web interface has no authentication layer.

SeverityCategoryFindingLocationTier
critical security Unauthenticated API endpoints in web frontend
Multiple SvelteKit API routes lack any authentication mechanism. The endpoints /chat, /api/youtube/transcript, /obsidian, and /notes are publicly accessible with no API key, session, or token validation. This allows unauthorized users to consume backend resources, call external APIs (YouTube transcripts), execute Fabric patterns, and write arbitrary files to the server filesystem.
 web/src/routes/chat/+server.ts:1 T1
critical security Arbitrary file write vulnerability in /notes endpoint
The /notes endpoint (web/src/routes/notes/+server.ts) writes user-supplied filename and content directly to the filesystem without validation. An attacker can use path traversal (e.g., '../../../etc/passwd') to write files outside the intended directory. No checks on filename format, content type, or file size. File permissions set to world-readable (0644).
 web/src/routes/notes/+server.ts:12 T2
critical security Command injection vulnerability in /obsidian endpoint
The /obsidian endpoint uses shell command execution (execAsync) with user-supplied input. Although the code attempts to escape shell arguments via escapeShellArg(), the function only escapes single quotes and may miss edge cases. The mkdir, echo, cp, ls, and wc commands execute user content. Attacker can craft malicious 'noteName' or 'content' values to break out of quotes and execute arbitrary commands.
 web/src/routes/obsidian/+server.ts:30 T2

CLI commands (fabric-cli, code2context, etc.) authenticate via environment variables (API_KEY, OPENAI_API_KEY, etc.), while the web interface has zero authentication at all—all endpoints are completely public. This creates a security inconsistency where the same AI provider credentials can be accessed by any network user via the web interface without authorization.
