Architecture Context

Jan is a local AI inference platform built as a Tauri desktop application with a React frontend. The architecture consists of: (1) Web UI layer using React 18 with i18n support, (2) Tauri native bridge providing IPC between frontend and backend, (3) Core TypeScript engine handling events, extensions, and model management, (4) Pluggable inference extensions supporting llama.cpp for general CPUs, MLX for Apple Silicon, RAG for document retrieval, and vector DB for embeddings, (5) Optional external API integration for cloud models (OpenAI, Anthropic, etc.). The app runs entirely locally with no mandatory cloud dependencies.
