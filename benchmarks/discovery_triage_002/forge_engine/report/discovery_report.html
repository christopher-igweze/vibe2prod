Architecture Context

FORGE is a Python-based LLM orchestration framework for automated code remediation. It follows a pipeline pattern: Discovery -> Triage -> Remediation -> Validation. The main entry points are a CLI (typer-based) and an AgentField agent. The execution engine uses checkpointing for resume capability, git worktrees for isolated fixes, and multiple specialized LLM agents for different roles. Configuration is partially centralized in ForgeConfig (Pydantic model) but scattered with magic numbers elsewhere. The codebase has a monolithic app.py orchestrator that needs decomposition. Tests include golden codebases with intentional vulnerabilities for detection testing.

critical security Command Injection via Unsanitized repo_url in Git Clone
In forge/app.py, the _resolve_repo_path function passes the user-supplied repo_url directly to subprocess.run for git clone without validating the URL scheme, format, or content. While shell=False prevents direct shell injection, git itself can interpret certain URL formats (e.g., git://host/repo, file:///etc/passwd, ext::command) in dangerous ways. The workspace name derived from the URL via regex is also used unsanitized as a directory path component. Multiple workers flagged this with high agreement.
